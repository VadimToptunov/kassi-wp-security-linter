Reports a shortcode callback that returns or echoes its attributes without escaping (CWE-79, Stored Cross-site Scripting). Contributors can write shortcodes, so [my_icon class='"><script>…'] runs in every visitor's browser, including administrators previewing the post.

Vulnerable

function my_icon_shortcode( $atts ) {
    $a = shortcode_atts( array( 'class' => '' ), $atts );
    return '<i class="' . $a['class'] . '"></i>';
}
add_shortcode( 'my_icon', 'my_icon_shortcode' );

Fixed

    return '<i class="' . esc_attr( $a['class'] ) . '"></i>';

sanitize_text_field() is not enough inside attributes: it keeps quotes. The callback must be in the same file as add_shortcode(). extract( $atts ) is not followed.

Rule WP-013 · CWE-79 · see the kassi-wp-rules repository for references.
