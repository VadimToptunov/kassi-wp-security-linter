Reports wp_redirect() to a URL that request data controls (CWE-601, Open Redirect). An attacker can send a link to your site that forwards the victim to any external site.

wp_safe_redirect() takes the same arguments but only follows hosts on the allowed_redirect_hosts list. A quick-fix switches to it.

Vulnerable

wp_redirect( $_GET['redirect_to'] );
exit;

Fixed

wp_safe_redirect( wp_unslash( $_GET['redirect_to'] ) );
exit;

Silent when the URL is built on a fixed base (admin_url(), home_url(), or add_query_arg() without a URL argument) or checked with wp_validate_redirect(). esc_url() does not prevent open redirects.

Rule WP-008 · CWE-601 · see the kassi-wp-rules repository for references.
