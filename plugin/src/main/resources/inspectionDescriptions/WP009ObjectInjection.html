Reports request data, including cookies, that reaches unserialize() or maybe_unserialize() (CWE-502, Deserialization of Untrusted Data). Unserializing attacker input can instantiate arbitrary objects; with a gadget chain in any active plugin, that means code execution, file deletion or data theft.

Vulnerable

$config = maybe_unserialize( base64_decode( $_POST['config'] ) );

Fixed

$config = json_decode( wp_unslash( $_POST['config'] ), true );

unserialize( $data, array( 'allowed_classes' => false ) ) is not reported. The flow is followed inside one function only.

Rule WP-009 · CWE-502 · see the kassi-wp-rules repository for references.
