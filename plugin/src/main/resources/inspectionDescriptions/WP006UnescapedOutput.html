Reports request data ($_GET, $_POST, $_REQUEST, $_SERVER['REQUEST_URI'], …) that is output with echo, print or <?= ?> without an escaping function (CWE-79, Cross-site Scripting).

Escape for the context: esc_html() for element content, esc_attr() inside attributes, esc_url() for URLs, esc_js() in inline JavaScript, wp_kses() when some HTML must be allowed.

Vulnerable

<input type="text" name="s" value="<?php echo $_GET['s']; ?>">

Fixed

<input type="text" name="s" value="<?php echo esc_attr( wp_unslash( $_GET['s'] ) ); ?>">

v0.1 reports reflected flows (input and output in the same function or template). It does not track values stored in the database. It treats sanitize_text_field() as safe, although inside an attribute it does not escape quotes.

Rule WP-006 · CWE-79 · see the kassi-wp-rules repository for references.
