Reports request data ($_GET, $_POST, $_REQUEST, $_COOKIE, REST parameters) that reaches the command argument of exec(), system(), shell_exec(), passthru(), popen() or proc_open() (CWE-78, OS Command Injection).

Shell metacharacters such as ;, |, && or $(...) in the request let an attacker run arbitrary commands on the server — remote code execution.

Vulnerable

$host = $_POST['host'];
system( 'ping -c 1 ' . $host );

Fixed

$host = $_POST['host'];
system( 'ping -c 1 ' . escapeshellarg( $host ) );

escapeshellarg() (around each argument) and escapeshellcmd() are the accepted defences; wp_unslash(), sanitize_text_field(), trim() and urldecode() do not neutralise shell metacharacters. An in_array() / ctype_* allow-list, or a capability check in the same function, lowers the severity. The flow is followed inside one function only.

Rule WP-015 · CWE-78 · see the kassi-wp-rules repository for references.
