Reports request data ($_GET, $_POST, $_REQUEST, $_COOKIE, REST parameters) that reaches the code argument of eval() or assert(), or the body argument of create_function() (CWE-94, PHP Code Injection).

Any PHP in the request then runs on the server — remote code execution.

Vulnerable

$formula = $_POST['expr'];
eval( '$result = ' . $formula . ';' );

Fixed

$formula = $_POST['expr'];
// Evaluate with a safe arithmetic parser, never eval().
$result = my_plugin_safe_math( $formula );

There is no escaping that makes evaluating request data as PHP safe — do not pass request data to eval(). An (int) cast, an in_array() / ctype_* allow-list, or a literal / option value are treated as safe. A capability check in the same function lowers the severity. The flow is followed inside one function only.

Rule WP-016 · CWE-94 · see the kassi-wp-rules repository for references.
