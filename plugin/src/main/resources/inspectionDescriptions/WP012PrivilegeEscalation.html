Reports request data that decides a user's role or capabilities: ->set_role(), ->add_role(), ->add_cap(), the 'role' of wp_insert_user() / wp_update_user(), or a *capabilities user meta value (CWE-269, Improper Privilege Management). A registration or profile form that accepts a role lets anyone become an administrator.

Vulnerable

$role = sanitize_text_field( $_POST['role'] );
if ( get_role( $role ) ) {
    $user->set_role( $role );
}

Fixed

$role = sanitize_key( $_POST['role'] );
if ( in_array( $role, array( 'subscriber', 'customer' ), true ) ) {
    $user->set_role( $role );
}

get_role() is not an allow-list: administrator exists too. An in_array() allow-list, or a fixed role, is recognised.

Rule WP-012 · CWE-269 · see the kassi-wp-rules repository for references.
