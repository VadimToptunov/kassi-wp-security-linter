Reports an AJAX (wp_ajax_*) or admin_post_* handler that changes state without verifying a nonce with check_ajax_referer(), check_admin_referer() or wp_verify_nonce() (CWE-352, Cross-Site Request Forgery).

Without a nonce, another site can make a logged-in administrator's browser send the request.

Vulnerable

add_action( 'admin_post_myplugin_delete', 'myplugin_delete' );
function myplugin_delete() {
    if ( ! current_user_can( 'manage_options' ) ) {
        wp_die();
    }
    delete_option( 'myplugin_settings' );
    wp_safe_redirect( admin_url() );
    exit;
}

Fixed

function myplugin_delete() {
    check_admin_referer( 'myplugin_delete' );
    if ( ! current_user_can( 'manage_options' ) ) {
        wp_die();
    }
    delete_option( 'myplugin_settings' );
    wp_safe_redirect( admin_url() );
    exit;
}

A capability check does not stop CSRF: an attacker's page acts with the victim's capabilities. The handler must be in the same file as its add_action() call. Updating the current user's own meta is not reported.

Rule WP-002 · CWE-352 · see the kassi-wp-rules repository for references.
