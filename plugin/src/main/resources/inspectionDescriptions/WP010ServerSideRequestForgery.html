Reports a URL from request data that is passed to wp_remote_get(), wp_remote_post(), wp_remote_request(), wp_remote_head() or download_url() (CWE-918, Server-Side Request Forgery). The server can be made to reach internal services, cloud metadata endpoints or the local network.

Vulnerable

$response = wp_remote_get( esc_url_raw( $_POST['image_url'] ) );

Fixed

$url = wp_http_validate_url( wp_unslash( $_POST['image_url'] ) );
if ( ! $url ) {
    wp_die();
}
$response = wp_safe_remote_get( $url );

esc_url_raw() cleans characters, not destinations. wp_safe_remote_*() rejects private and loopback addresses. An allow-list check on a derived host variable is not recognised.

Rule WP-010 · CWE-918 · see the kassi-wp-rules repository for references.
